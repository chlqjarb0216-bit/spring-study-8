# 1.
## JSON 이란 무엇인가?
JavaScript Object Notation. 자바스크립트 오브젝트를 기반으로 한 데이터 표기법으로 데이터를 텍스트로 교환하는데 특화되어 있다.
기본적으로 키:값 쌍과 배열 구조로 이루어져 있으며 문자열, 숫자, true/false, null의 자료형을 지원할 수 있다.

## JSON 과 XML 의 차이
기존에 존재하던 XML은 헤더에 데이터 스키마를 기술하여야하고 태그를 열고 닫는 등 데이터 외의 정보가 많아 간단하고 작은 데이터를 보낼때는 데이터보다 데이터 외의 정보가 많아지는 경우가 발생했다. 이를 해결하기 위해 만들어진 것이 JSON이다. 
JSON은 별도의 스키마가 존재하지 않으며 태그를 열고 데이터를 기술한 뒤 태그를 닫는 대신 키:값으로 비교적 간단하게 데이터를 표현함으로써 데이터 전송에 따른 네트워크 부하를 줄일 수 있었다.
다만 스키마를 기반으로 자동적으로 파싱해주는 XML에 비해 JSON은 사용자가 파싱 및 검증에 시간을 쏟아야 하는 단점이 있다.
그러나 특정 데이터 구조에 대한 JSON검증 및 파싱하는 라이브러리를 만들어 송신측과 수신측이 공유한다면 이러한 단점을 극복할 수 있으리라 본다.


# 2.
## API 란 무엇인가?
Application Programming Interface. 
서로다른 소프트웨어 사이에서 데이터를 주고받고 기능을 공유할 수 있도록 해주는 규칙을 정의한 사양서를 말하나, 대부분 API를 말할 때는 그 사양서를 기반으로 구현된 라이브러리를 말하는 것에 해당된다. 
즉, 한 소프트웨어의 기능을 사용하거나, 데이터를 받아올때 대상 소프트웨어의 내부 구현을 알 필요없이 사용할 수 있도록 만들어주는 규칙을 말한다.

## 오픈 API란 무엇인가?
누구나 자유롭게 사용할 수 있도록 공공기관이나 기업 등이 공개한 API이다.

## API 통신에서 요청과 응답은 무엇인가?
웹 API에서 요청이란 특정 url(과 필요하다면 데이터)을 기반으로 서버에 데이터( 혹은 데이터의 처리)를 요구하는 행위이며, 응답은 요청에 따라 서버에서 전송받은 데이터( 혹은 결과)를 말한다.


# 3.
## 자바 상속과 인터페이스란?
상속이란 해당 클래스의 모든 기능을 포함하는 자식 클래스를 만드는 것을 말하며, 인터페이스란 클래스 단위 상속이 아닌 특정 기능군을 구현하기 위한 설계도를 말한다.
포유류라는 클래스의 하위 클래스로 개라는 클래스를 만드는 것이 상속이고 날 수 있다 라는 기능을 새라는 클래스 박쥐라는 클래스에 구현하는 것이 인터페이스 구현이라 볼 수 있겠다.

## 메소드 재정의 (오버라이드) 란?
오버라이드란 상속받은(혹은 구현된) 메소드를 그 클래스에 맞게 재구현하는 것으로 외부에서 해당 클래스에 대한 상세정보를 몰라도 상위 클래스(혹은 인터페이스)를 기반으로(다형성) 메소드를 호출하였을때 제 기능을 할 수 있도록 해준다.
